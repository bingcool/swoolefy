# I18n：请求语言协商 + Symfony Translation

> **状态**：已落地（`LocaleMiddleware` + stub + create）。  
> 语言包与 Translator 在**应用侧**；协商中间件在框架 `src/Http/Middleware/`。

## 定位

每个 HTTP 请求协商出 locale，写入协程 Context（默认键 `lang_locale`），再由 `translator` 组件按该 locale 加载 PHP 语言包。

| 目标 | 做法 |
|------|------|
| 请求级语言 | `LocaleMiddleware::apply` → `Context::set('lang_locale', …)` |
| 翻译实现 | Symfony `Translator`（`composer` 已 require `symfony/translation`） |
| 语言包 | `APP_PATH/Resource/Translations/{locale}/messages.php` |
| 全局默认 | Bootstrap 里调用 `LocaleMiddleware::apply`（create 已生成） |

## 三行用法

```php
use Swoolefy\Core\Application;
use Swoolefy\Http\Middleware\LocaleMiddleware;

// 1. 协商 locale → Context lang_locale（Bootstrap 或路由中间件）
LocaleMiddleware::apply($requestInput);

// 2. 取 Translator（按 Context 加载语言包）
$t = Application::getApp()->get('translator');

// 3. 翻译
echo $t->trans('hello');
```

## 协商优先级

从高到低：

1. Query：`lang` / `locale`
2. Header：`X-Locale` / `X-Language`
3. Header：`Accept-Language`（解析逗号分隔列表，匹配白名单）
4. 配置 `default_locale`（`Config/i18n.php`）

仅 `allowed_locales` 中的值会写入 Context；未知 tag（如 `fr`）回落默认。`en-US` 可匹配白名单中的 `en`。

---

## 配置（Config/i18n.php）

```php
<?php

return [
    'default_locale' => env('I18N_DEFAULT_LOCALE', 'zh_CN'),
    'fallback_locale' => env('I18N_FALLBACK_LOCALE', 'en'),
    'allowed_locales' => ['zh_CN', 'en'],
    'context_key' => 'lang_locale',
    'query_keys' => ['lang', 'locale'],
    'header_keys' => ['x-locale', 'x-language'],
];
```

| 键 | 说明 |
|----|------|
| `default_locale` | 协商失败时的默认值 |
| `fallback_locale` | Translator 资源缺失时的回退 locale |
| `allowed_locales` | 允许写入 Context 的白名单 |
| `context_key` | 协程键名，须与 translator 组件一致 |

## Bootstrap 全局注册（推荐）

```php
<?php

namespace App;

use Swoolefy\Core\BootstrapInterface;
use Swoolefy\Http\Middleware\LocaleMiddleware;
use Swoolefy\Http\Middleware\SecurityHeadersMiddleware;
use Swoolefy\Http\RequestInput;
use Swoolefy\Http\ResponseOutput;

class Bootstrap implements BootstrapInterface
{
    public static function handle(RequestInput $requestInput, ResponseOutput $responseOutput)
    {
        SecurityHeadersMiddleware::apply($requestInput, $responseOutput);
        LocaleMiddleware::apply($requestInput);
    }
}
```

在 `Protocol/conf.php` 中：

```php
'application_bootstrap' => \App\Bootstrap::class,
```

---

## 路由挂载（可选）

若已在 Bootstrap 全局 `apply`，一般无需再挂路由。

```php
<?php

use Swoolefy\Http\Middleware\LocaleMiddleware;
use Swoolefy\Http\Route;

Route::group([
    'middleware' => [LocaleMiddleware::class],
], function () {
    // ...
});
```

## Translator 组件

`Config/component/translator.php`（create 已复制）按 Context 中的 locale 加载：

```text
APP_PATH/Resource/Translations/{locale}/messages.php
```

语言包示例：

```php
<?php

// Resource/Translations/zh_CN/messages.php
return [
    'hello' => '你好 swoolefy',
];
```

```php
<?php

// Resource/Translations/en/messages.php
return [
    'hello' => 'Hello swoolefy',
];
```

Controller 中：

```php
$t = \Swoolefy\Core\Application::getApp()->get('translator');
return [
    'msg' => $t->trans('hello'),
];
```

联调示例：

```bash
curl -s 'http://127.0.0.1:9501/api/index/index?lang=en' -H 'Accept: application/json'
curl -s 'http://127.0.0.1:9501/api/index/index' -H 'Accept-Language: zh-CN'
```
