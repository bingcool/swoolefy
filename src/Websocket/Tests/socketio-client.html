Swoolefy WebSocket Socket.IO 测试页

先启动示例应用：SWOOLEFY_CLI_ENV=dev php cli.php start WebsocketService
推荐同源访问（polling 必须）：http://127.0.0.1:9508/socketio-client.html （需 accept_http=true）
也可 php -S 127.0.0.1:8888 -t src/Websocket/Tests 打开 http://127.0.0.1:8888/socketio-client.html。
勿用 file:// 双击打开——浏览器会拦截 polling 的 XHR，仅 websocket 可用。
事件映射见示例应用 WebsocketService/Config/socketio.php： group.join → Service/Chat/JoinGroup， chat.send → Service/Chat/Send。
